## 👋 About This Repository

This repository contains beginner-friendly Node.js examples covering built-in modules, file handling, custom modules, npm, and a basic Express server. All files are kept in the repository root for easy access.

## 📁 Project Structure

```text
NODE-JS/
├── README.md
├── package.json
├── demo.js
├── registration.js
├── system_info.js
├── file_async.js
├── file_sync.js
├── server.js
├── sample.txt
└── sample2.txt
```

## 📚 Topics Covered

| File | What it demonstrates |
|---|---|
| `system_info.js` | The Node.js `os` module |
| `file_async.js` | Asynchronous file read/write using `fs` |
| `file_sync.js` | Synchronous file read/write using `fs` |
| `demo.js` | Calling a custom module and checking a sample user |
| `registration.js` | Exporting functions with `module.exports` |
| `server.js` | Basic Express server with `/` and `/health` routes |
| `sample.txt`, `sample2.txt` | Files used by the filesystem examples |

## ▶️ Run Locally

Install [Node.js](https://nodejs.org/), then run these commands from this folder:

```bash
npm install
npm run system-info
npm run file:async
npm run file:sync
npm start
```

Start the Express server:

```bash
npm run serve
```

Then open `http://localhost:3000` in your browser. The health endpoint is at `http://localhost:3000/health`.

## 🔐 Good Practices

- Keep files named clearly, even when all of them live in one folder.
- Use asynchronous file operations in typical application code.
- Never commit API keys, passwords, or private credentials.
- The registration function is only a learning example; it does not connect to a database.
